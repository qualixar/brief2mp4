# brief2mp4 docs

Three guides for people. The agent reads the skill's own files (`plugin/skills/brief2mp4/SKILL.md` and `references/`); these are for you, to understand what it does and to get more out of it.

| Guide | Read it when |
|---|---|
| [Getting started](getting-started.md) | You are installing brief2mp4 on macOS, Windows or Linux and want your first video |
| [Architecture](architecture.md) | You want to know how the loop, the routing and the checks work, or you want to extend it |
| [3D walkthrough](3d-walkthrough.md) | Your brief has a 3D product, physics, an exploded view or a turntable |
